# Qoder adapter

Qoder supports user-level and project-level Skills.

User-level:
`~/.qoder/skills/project-handoff/SKILL.md`

Project-level:
`.qoder/skills/project-handoff/SKILL.md`

Use the shared project `AGENTS.md` as the project instruction entrypoint where supported by your Qoder mode/version.

After adding or updating a Skill in an active Qoder CLI session, reload Skills if needed.
