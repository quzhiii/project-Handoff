# Presets

`project-handoff` supports two project sizes. Start small and add files when coordination cost grows.

## Lite Preset

Use for solo projects, prototypes, small repos, and low-risk iterations.

Required files:

1. `AGENTS.md`
2. `BRIEF.md`
3. `STATE.md`
4. `TASK.md`

Optional files:

- `DECISIONS.md`
- `ROADMAP.md`
- `EXECUTION_RECEIPT.md`
- `REVIEW_RESULT.md`
- `SNAPSHOT_MANIFEST.md`

Recommended rule: record only current goal, current state, current task, branch, commit, and next action.

## Full Preset

Use for multi-agent projects, active collaboration, frequent handoffs, or work with durable architecture and product decisions.

Recommended files:

1. `AGENTS.md`
2. `BRIEF.md`
3. `STATE.md`
4. `DECISIONS.md`
5. `TASK.md`
6. `ROADMAP.md`
7. `EXECUTION_RECEIPT.md`
8. `REVIEW_RESULT.md`
9. `SNAPSHOT_MANIFEST.md`

Recommended rule: keep decisions durable, keep tasks narrow, and use execution receipts for review.

## Upgrade path

Move from Lite to Full when any of these happen:

- more than one agent or person is changing project direction;
- rejected options need to stay visible;
- handoff frequency increases;
- release, review, or audit trails matter;
- roadmap items are being confused with current scope.
